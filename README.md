# Waschpark Wuppertal – Webseiten-Entwurf

Musterseite für die Waschpark Wuppertal GmbH im Stil des neuen Flyers, mit einer Scroll-Animation:
ein Auto fährt durch die Waschstraße.

Die Seite ist passwortgeschützt. Der Inhalt liegt nur verschlüsselt im Repository
(AES-256-GCM, Schlüssel per PBKDF2 aus dem Passwort) und wird erst im Browser entschlüsselt.
Die Preise sind noch Platzhalter.
